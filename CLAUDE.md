# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is a Claude Code user environment containing several independent projects for Japanese healthcare business automation and financial reporting.

---

## Projects

### 1. care-facility-automation (Python)
**Path:** `Documents/Claude/Projects/株式会社健康会/care-facility-automation/`

Automates care record aggregation, monthly report generation, and insurance claims calculation for care facilities.

**Setup:**
```bash
pip install -r config/requirements.txt
```

**Run scripts in order:**
```bash
python scripts/generate_sample_data.py       # One-time: seed initial data
python scripts/aggregate_daily_records.py    # Aggregate daily care records
python scripts/calculate_claims.py           # Calculate care insurance claims
python scripts/generate_monthly_report.py    # Generate Excel monthly report
python scripts/export_for_looker.py         # Export flat CSV for Looker Studio
```

**Config:** `config/settings.json` — controls facility info, file paths, target year/month, and care service codes.

**Data flow:** `data/*.xlsx` / `data/*.csv` → scripts → `output/`

### 2. Management Report Generators (JavaScript/Node.js)
**Paths:** `Documents/Claude/Projects/株式会社健康会/FY2602/` and `FY2702/`

Generates multi-sheet Excel workbooks (P&L, BEP analysis, staffing dashboards) from facility CSV files. Each fiscal year directory is self-contained.

**Run:**
```bash
cd "Documents/Claude/Projects/株式会社健康会/FY2602"
PL_BASE_DIR="." node generate_management_report.js
```

**Facilities in CSV data:** CA元町, CA栄町, CA菊水, GH (グループホーム), MH (メンタルヘルス)

**Columns span:** 12 months (R7/3 through R8/2) + annual total

**Dependencies:** `exceljs`, `iconv-lite` (Shift-JIS encoding for Japanese text)

### 3. 連結試算表 (Consolidated Trial Balance)
**Path:** `Documents/連結精算表/`

Excel-based consolidated financial reporting for a 13-entity healthcare group. Has its own `CLAUDE.md` in that directory — always read it before making changes.

**Critical rules (from that CLAUDE.md):**
- Fonts: MS PGothic (text) / Arial (numbers) only — Noto Sans is forbidden
- Font size: 11pt uniform
- Colors: white background + navy blue only
- After each update: confirm Noto Sans count = 0, BS balance = ¥0, then increment version number

**Monthly update workflow:** Place each entity's 試算表 CSV in the folder, then instruct "月次更新して".

## Architecture Notes

### Python automation suite
Scripts are independent and stateless — each reads from `data/` and writes to `output/`. There is no shared state between scripts. Run them in the listed order because later scripts depend on files generated by earlier ones.

### JavaScript report generators
Each `.js` file in FY2602/FY2702 is a standalone generator. `generate_management_report.js` is the main entry point; it calls or references the others. CSV files are loaded directly by filename — adding a new facility requires updating the file-list array at the top of the script.

### Financial data conventions
- Fiscal years use Japanese imperial year format: R7 = 令和7 = 2025, R8 = 令和8 = 2026
- Care insurance unit price: ¥11.40/unit (configured in settings.json)
- Consolidation eliminations for the 13-entity group are hardcoded in the 連結精算表 CLAUDE.md
